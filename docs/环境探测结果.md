## 6. 探测结论 → 决策落定

| 待确认项 | 结论 | 影响的设计决策 |
|---|---|---|
| 网络模式 | ✅ **NAT（VMnet8）**，网关 192.168.10.2，ens33=192.168.10.102/24 | IP 直连策略确认；无需 hosts 解析 |
| HMS 可远程直读 | ✅ MySQL 3306 全接口监听，Windows 已测通 | **采集主路径 = HMS 直读**（连接串 host 由 hadoop102 改写为 192.168.10.102） |
| HMS 账号 | `root` 密码已确认（存 gitignore 的 config，不入库） | 直读采集已实测通过（115 表） |
| **DS 版本** | ⚠️ **1.3.9** | **OpenAPI 按 1.x 适配**：`POST /dolphinscheduler/login` 拿 sessionId，后续请求带 sessionId；无 token/generate 接口。Phase 4 按此实现 |
| Hive 服务 | ✅ HS2（10000）已启动，Windows 已连通 | 可直接对接 HS2 执行 SQL（metastore 本地模式，无需 9083） |
| HMS host 为 hostname | hive-site 中 ConnectionURL 用 `hadoop102` | 平台 datasource 表存 IP：`192.168.10.102:3306` |
| Spark 引擎 | 未部署 STS/Livy | SQL 引擎仅接 Hive；Spark 列为 Phase 6 可选增强 |
| Flume/Superset | 不在 PATH | 与平台无耦合，忽略 |
| 宿主机资源 | 内存 31.7GB / Python 3.11.5 / Node v25 | 满足预算；Node v25 在 Phase 1 验证 Vite 兼容性 |
| YARN RM 位置 | ✅ 在 hadoop103（8088），102/104 无 | 平台不依赖 RM UI，无需处理 |
| DS 部署形态 | API 仅在 102（12345），worker 三台都有 | 平台只对接 `192.168.10.102:12345` 单点 |
